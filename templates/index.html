Pro Mode (off by default)

Flip this on to let Apply All Tweaks include the latency/perf tweaks that have real benefit but real side-effects — the kind you only want if you know what you're trading. When off, Apply All stays on the safe path.

Behind the gate: VBS / HVCI / Credential Guard disable (weakens kernel-driver attack hardening), Spectre/Meltdown mitigations disable (~5-8% on storage-heavy workloads, vanishingly small on game FPS), HPET disable (can cause clock drift / monitor wake failures on some chipsets), bcdedit disabledynamictick (laptop battery murderer), MPO disable (obsolete NVIDIA workaround; now causes HDR/G-Sync hand-off issues), blanket USB MSI mode (Code 10 on some controllers), raised GPU TDR delays (10 s desktop hang on driver fault instead of 2 s), Windows Search disable (breaks Start Menu search), Memory Compression disable (only helps with 32 GB+ RAM), hibernation off (laptops lose the feature).

What happens when a game is detected
When any game from the database launches, Vispora automatically applies these tweaks and reverts them all when the game closes:
1. Process priority → High
2. CPU affinity locked to P-Cores (hybrid CPUs) or all cores
3. Win32PrioritySeparation = 0x28 (Short/Fixed — lowest input lag)
4. CPU idle states disabled (max clock speeds)
5. DSCP 46 network priority for the game
6. SystemResponsiveness = 10 (foreground priority, audio-safe)
7. Network throttling disabled
When the game exits, everything above is reverted AND a PC refresh runs automatically:
→ Working sets dumped, standby cleared (frees 1–4 GB)
→ DNS cache flushed
→ Orphaned game processes killed (Epic Web Helper, Unreal CEF, shader compilers)
→ MMCSS multimedia scheduler restarted
→ Stale shader-cache .lock and .tmp files deleted

Aim at any target in your game (no screen capture, so windowed mode not required). Click Start, then fire your full magazine while manually compensating — drag your mouse down or push your right stick down to keep the crosshair on target. We record what you do. Quality depends on your counter-pull technique. Practice the spray a few times first; your last attempt is usually the cleanest.
📹 Capture from gameplay (screen tracking)
Aim at a flat wall in your game (windowed or borderless), click Start, fire your full magazine without moving your aim (don't touch the right stick / mouse). We screenshot the foreground window at 120 Hz and use FFT-based phase correlation to extract the camera-drift pattern. After firing, click Stop (or wait for the duration to elapse) and save as a preset.

Controller user? Enable Auto-fire below — Vispora will push RT through your virtual pad so you don't have to hold the trigger yourself. Requires virtual_controller mode + master switch on.
